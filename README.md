# 🐍 Estudos de Python — Curso Senac

Este repositório reúne os algoritmos, exercícios e pequenos projetos que desenvolvi ao longo do curso de **Python** realizado no **Senac**. A ideia é manter um histórico público da minha evolução na linguagem, servindo tanto como portfólio quanto como material de consulta para revisão futura.

## 📌 Sobre o repositório

Aqui você vai encontrar códigos que abordam desde conceitos básicos até tópicos mais avançados trabalhados em sala de aula, como:

- Lógica de programação e estruturas condicionais
- Laços de repetição (`for`, `while`)
- Listas, tuplas, dicionários e conjuntos
- Funções e manipulação de strings
- Programação orientada a objetos (POO)
- Manipulação de arquivos
- Tratamento de exceções
- Pequenos projetos práticos propostos durante o curso

Cada arquivo representa um exercício ou desafio proposto pelo instrutor, geralmente organizado por aula.

## 🗂️ Estrutura do repositório

```
📁 aula-python-senac/
├── 📁 aula-02/

├── 📁 aula-04/

```

> A organização pode variar conforme o andamento do curso — novas pastas serão adicionadas à medida que os módulos avançam.

## 🛠️ Tecnologias utilizadas

- **Python 3**
- Bibliotecas nativas da linguagem (conforme necessidade de cada exercício)

## ▶️ Como executar os códigos

1. Clone o repositório:
   ```bash
   git clone https://github.com/lotufo22/aula-python-senac.git
   ```
2. Acesse a pasta do exercício desejado:
   ```bash
   cd aula-python-senac/aula-01
   ```
3. Execute o arquivo Python:
   ```bash
   python nome_do_arquivo.py
   ```
